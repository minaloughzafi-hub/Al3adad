عداد الذكر — PWA + APK

1) أنشئ repo جديد (مثلا counter) وارفع الملفات العادية بـ Upload files (ضروري splash.jpg).
2) أنشئ الملف .github/workflows/build-apk.yml (Add file > Create new file) والصق فيه محتوى build-apk.yml.
3) فتبويب Actions غادي يبدا البناء (3-6 دقايق).
4) فتبويب Releases غادي تلقى counter.apk. حملو وثبتو.
